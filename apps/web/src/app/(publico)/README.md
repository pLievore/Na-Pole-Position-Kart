# Área pública

Acessível sem login. Nada aqui pode consultar dado pessoal — use sempre
`paraRankingPublico()` de `@napole/core` ao montar listas de pilotos.

Telas previstas (seção 18 do escopo):

| --- | --- | --- |

| `/regras` | Regras do ranking | 17 |
| `/cadastro` | Cadastro de piloto | 2.1 |
| `/entrar` | Login do piloto | — |
| `/termos`, `/privacidade` | Termos e LGPD | 2.1 |
